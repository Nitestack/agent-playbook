# Security

Report a vulnerability in the guard hooks or the scripts privately, through GitHub's "Report a vulnerability" button on the Security tab of this repository. Please do not open a public issue for it.

The guards stop a well-meaning agent from drifting. They are not a defense against a determined adversary, so a bypass by a deliberately hostile agent is a known limit, not a vulnerability. A guard that allows an ordinary, documented action it claims to deny is a bug: open an issue, or a private report if it affects credentials or publishing.
